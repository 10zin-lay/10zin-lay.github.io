Arduino Gripper Force Controller

Arduino C/C++ Servo Control Force Sensing
+

Overview

Embedded firmware for the servo-actuated gripper. Reads a force-sensitive resistor and closes a PID loop to maintain target grip force. Serial interface for tuning gains and logging data in real time. Fully open-source on GitHub.

Key outcomes

  • FSR-based closed-loop grip force control
  • PID tuning via serial terminal
  • Real-time data logging at 100 Hz
  • Under 4 KB flash footprint on Arduino Nano
